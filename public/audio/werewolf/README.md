# Werewolf audio cues

These are short, normalised game cues prepared for the Werewolf table game. Long source recordings are not shipped: only the useful clips are kept here.

| File | Use | Length |
| --- | --- | ---: |
| `night-forest-loop.mp3` | Night atmosphere; safe to loop | 30s |
| `sleep-breathing-loop.mp3` | Sleeping/night role atmosphere; safe to loop | 12s |
| `werewolf-howling.mp3` | Distant howl at nightfall | 1.32s |
| `werewolf-growl.mp3` | Lower filtered howl variant | 1.32s |
| `player-death-scream.mp3` | Player eliminated/death cue | 3.61s |
| `next-turn.wav` | Phase/turn transition | 1.00s |
| `countdown-tick.wav` | Countdown tick | 0.12s |
| `countdown-final.wav` | Final countdown warning | 0.50s |

## Sources and usage

- [Pixabay — Wolf Howl by DRAGON-STUDIO](https://pixabay.com/sound-effects/wolf-howl-474056/): downloaded under the Pixabay Content License. `werewolf-growl.mp3` is a pitch/filter treatment of the same source.
- [Pixabay — Male Scream by Universfield](https://pixabay.com/sound-effects/film-special-effects-male-scream-121085/): downloaded under the Pixabay Content License.
- [Pixabay — Night Forest with Frogs and Crickets for Sleep by Eryliaa](https://pixabay.com/sound-effects/nature-night-forest-with-frogs-and-crickets-for-sleep-451153/): only a 30-second excerpt is shipped.
- [Pixabay — Snoring Sound Effect / Deep Sleep Breathing by masirez](https://pixabay.com/sound-effects/people-snoring-sound-effect-deep-sleep-breathing-304270/): only a 12-second excerpt is shipped.
- [Dustyroom — Free Casual Game Sounds](https://dustyroom.com/free-casual-game-sounds/): `DM-CGS-04`, `DM-CGS-21`, and `DM-CGS-02`, converted from WAV to mono WAV for the transition/countdown cues. The pack is published as CC0.

The Atelier Magicae werewolf pack was downloaded for local evaluation only. Its included usage note permits use but says not to redistribute, so no Atelier files are included in this folder or the web build.
